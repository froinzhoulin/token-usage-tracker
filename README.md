# Token Usage Tracker

本地运行的 **Token 用量统计与分析桌面应用**（个人单机工具，数据保存在本机）。

## 功能概览

- **数据接入**：用量记录文件导入（JSON / CSV / NDJSON，可自定义字段映射）、实时事件采集、手动录入
- **统计与趋势分析**：汇总看板、时间趋势图、按模型/会话/项目/标签的维度分布
- **成本核算**：内置 DeepSeek / OpenAI / Anthropic 单价库，支持自定义模型单价，自动换算费用
- **明细查询**：分页明细、过滤排序、图表钻取
- **报表导出**：CSV / Excel / JSON / 图片
- **预算告警**：按日/月/维度设置预算，达到阈值提醒

## 技术方向（待评审确认）

Tauri 2（Rust） + React/TypeScript + ECharts + SQLite，Windows 优先、跨平台兼容。

# Token Usage Tracker — v0.2 轻量版功能整理

> 依据用户 2026-09 反馈重写方向：**检测本机使用 token 的情况，主要面向国产大模型，第一版尽量简单**。
> 取代此前 v0.1 的"账单/CSV 分析"取向。原实现保留(统计引擎/SQLite/看板组件)，本版为裁剪目标。

---

## 一句话定位

本机常驻的小桌面工具：你电脑上的程序（或你自己的代码）调用国产大模型时，它把每次用量记下来，你随时打开看板就知道"今天/这个月花了多少 token、多少钱、哪个模型用的多"。

## 用户场景（默认假设，可改）

你（或你写的脚本/工具）通过 API 使用 **DeepSeek / Kimi / 智谱GLM / 通义Qwen / 豆包** 等国产模型；这些调用发生在这台电脑上；你想不翻各家后台就看到累计用量与费用。

## 简单版功能清单（v0.2，全部保留在此）

1. **用量收集（三选一，见下方待确认项 A）**
   - A1 本地端点：工具开一个 127.0.0.1 小接口，你的程序每次调用完 POST 一条用量即可（一条 curl/几行代码接入）。
   - A2 本地代理：把调用方的 base_url 指向 `127.0.0.1:端口`，工具自动转发到真实厂商并记录（任何 OpenAI 兼容客户端都可用，DeepSeek/Kimi/GLM/Qwen 都兼容）。
   - A3 粘贴/文件：手动贴一条 JSON 或丢一个 JSONL/CSV 文件，自动识别入库（最笨但零接入）。
2. **国产价目表（内置可改）**
   - 预置 DeepSeek / Kimi / GLM / Qwen / 豆包 主要模型 每百万 token 输入/输出价（人民币）；
   - 未知模型可手动补价；只有估算用，调用返回的官方用量优先。
3. **看板（一屏）**
   - 顶部：今日/近7天/总 Token（输入/输出/缓存）、估算费用；
   - 中部：按天小趋势图；
   - 下部：按模型用量排行（条形）。
4. **明细（简单）**
   - 最近记录列表：时间、模型、输入/输出/总 token、费用、来源会话；
   - 支持删除、清空；不做复杂筛选/编辑/标签。
5. **常驻与提醒（可后续）**
   - 缩小到托盘继续收集；费用超预算提醒 → 放 v0.3，不在第一版。

## 明确不做（第一版）

- 不做 OpenAI/Anthropic 界面化强调（有国产模型就够了，其它按自定义价兜底）
- 不做 CSV 字段映射向导、报表 Excel、多维度分析、项目标签体系
- 不做账号/云同步/多用户
- 不做会话内容解析
